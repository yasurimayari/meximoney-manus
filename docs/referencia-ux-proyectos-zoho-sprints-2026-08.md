# Referencia de UX para Proyectos

Fuente revisada el 27 de agosto de 2026: [Zoho Sprints](https://www.zoho.com/es-xl/sprints/?src=zGlobalAllProducts&sredirect=true).

La referencia utiliza un espacio de trabajo central para que una persona pueda orientar rápidamente su trabajo, priorizar elementos pendientes, visualizar el flujo entre estados y revisar el avance. Para Meximoney, se trasladarán únicamente estos principios de experiencia, no el diseño visual ni la mecánica de colaboración de Zoho: una entrada principal de planificación, una vista de trabajo enfocada, estados claros, conteos útiles, acciones cercanas al contexto y cambios de vista sin pérdida de información.

Meximoney conservará su alcance personal y manual. No añadirá colaboración, sprints, integración de terceros, automatización financiera ni registros de tiempo a partir de esta referencia.
